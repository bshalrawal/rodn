┌─────────────────────────────────────────────────────────────────────────────┐
│ ENVIRONMENT VARIABLES (REQUIRED BEFORE PRODUCTION)                          │
└─────────────────────────────────────────────────────────────────────────────┘

   JWT_SECRET
   ├─ What: JWT token signing secret
   ├─ Length: 32 bytes (64 hex characters)
   └─ Generate: node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

   JWT_REFRESH_SECRET
   ├─ What: Refresh token signing secret
   ├─ Length: 32 bytes (64 hex characters)
   └─ Generate: node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

   SESSION_SECRET
   ├─ What: Express session signing secret
   ├─ Length: 32 bytes (64 hex characters)
   └─ Generate: node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

   CORS_ORIGIN
   ├─ What: Allowed cross-origin domain
   ├─ Example: https://rodb.news
   └─ Note: REQUIRED in production, fails without it

   NODE_ENV
   ├─ What: Environment indicator
   ├─ Value: production (for production deployment)
   └─ Note: Enables security validations
