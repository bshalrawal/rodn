# Render Deployment - Step-by-Step Setup

## 🚀 Complete Instructions to Deploy RODB to Render

---

## Step 1: Sign Up & Connect GitHub

1. Go to https://render.com
2. Click **Sign up** → Choose **GitHub**
3. Authorize Render to access your GitHub account
4. Grant access to repository: `rodn`

---

## Step 2: Create Web Service

1. Click **Dashboard** (top right)
2. Click **New +** → Select **Web Service**
3. Select repository: `gneshpoudel-art/rodn`
4. Click **Connect**

---

## Step 3: Configure Service

Fill in the form:

```
Name:                 rodb-news-platform
Environment:          Node
Build Command:        npm install
Start Command:        npm start
Plan:                 Starter (free)
Repo Branch:          main
Autogenerated Domain: (leave as-is)
```

## Step 5: Start Initial Deployment

Click **Create Web Service** button at bottom

The service will:
1. Build your code (npm install)
2. Start the server (npm start)
3. Initialize database
4. Deploy and expose URL

**This takes 2-5 minutes.**

## Step 6: Monitor Deployment

1. You'll see **Logs** appear in real-time
2. Look for these success messages:
   ```

   Default data seeded
   ```

## Step 8: Configure Scheduled Jobs (Cron)

Render has native **Scheduled Jobs** but they require the service URL.

### Option A: Use Render Dashboard (Recommended)

1. Go to your service page
2. Click **Scheduled Jobs** tab
3. Click **New Scheduled Job**

**Create Job 1: Publish Articles**
```
Name:     publish-scheduled-articles
Schedule: 0 */6 * * *
Method:   GET
Endpoint: /api/cron/publish-scheduled-articles
Headers:  
  Header Name: x-cron-secret
  Header Value: 4c96737218b2babf087fa303731be2c91e08c7821ae1c685ddd4c68ff4c4208c
Timezone: UTC
```

**Create Job 2: Cleanup Logs**
```
Name:     cleanup-old-logs
Schedule: 0 2 * * *
Method:   GET
Endpoint: /api/cron/cleanup-old-logs
Headers:
  Header Name: x-cron-secret
  Header Value: 4c96737218b2babf087fa303731be2c91e08c7821ae1c685ddd4c68ff4c4208c
Timezone: UTC
```

### Option B: Use render.yaml (Already Done!)

We've already created `render.yaml` with cron config. 
- If you used render.yaml during setup, jobs are auto-created
- Otherwise, manually create in Dashboard (Option A)

1. Click **Settings** → **Custom Domain**
2. Enter your domain: `yourdomain.com`

4. Update your DNS provider (GoDaddy, Cloudflare, etc.)
5. SSL certificate auto-generates (free)

## ❌ Troubleshooting

### Service Won't Start
**Check logs:**
1. Logs tab should show build errors
2. Common issues:
   - Missing npm package: Run `npm install` locally
   - PORT not set: Render sets PORT=10000
   - Node version: Must be 18.x+

### Database Connection Error
**Fix:**
1. Verify TURSO_CONNECTION_URL (exact copy from Turso)
2. Verify TURSO_AUTH_TOKEN (full token, no spaces)
3. Test locally with these env vars

### Cron Jobs Not Running
**Fix:**
1. Verify headers include `x-cron-secret`
2. Check service is healthy: `/api/health` should return 200
3. Logs should show job execution at scheduled time
4. Try manually: `curl https://your-url/api/cron/publish-scheduled-articles -H "x-cron-secret: ..."`

### Files Disappear After Restart
**Solution:** Render's filesystem is ephemeral (temporary)
- Use S3, Backblaze B2, or Vercel Blob for uploads
- See [RENDER_DEPLOYMENT_GUIDE.md](RENDER_DEPLOYMENT_GUIDE.md) for details
